# Contributing

Contributions should support Aether's user-choice principles and keep evidence separate from assumptions.

1. Read [AGENTS.md](AGENTS.md), relevant architecture docs, and existing decision records.
2. Keep changes focused; update documentation and experiment records with implementation changes.
3. Run `make validate` and `make test` where the environment supports them. Record unavailable checks rather than claiming success.
4. Use Conventional Commits (for example, `docs: add recovery evaluation framework`).
5. Open a pull request with purpose, changes, validation performed, results, and limitations.

Do not include secrets, personal data, generated VM disks, or unreviewed ISO artifacts. See [Security](SECURITY.md).
