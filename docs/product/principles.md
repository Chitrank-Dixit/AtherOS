# Product principles

- **Choice by default:** GNOME, KDE Plasma, and Hyprland are selectable; no desktop is mandatory.
- **Independent capabilities:** developer profiles do not require AI, and AI is optional.
- **Reproducibility and recovery:** make system changes understandable and provide a path back.
- **Respect the user:** preserve user data and configuration and explain system-wide operations.
- **Secure boundaries:** privileged work is mediated by a controlled broker, never unrestricted root commands from product UI.
- **Evidence before commitment:** distinguish measured behavior from research and assumptions.
